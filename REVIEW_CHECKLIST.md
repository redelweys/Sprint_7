# Перед сдачей

- Один тест проверяет одно действие. Подготовка идёт до запроса, проверки — в конце.
- Фикстуры готовят данные и убирают их после теста, даже при падении проверки.
- Варианты сценария задаются параметризацией, без ветвления в тесте.
- Каждый HTTP-запрос оформлен именованной функцией с шагом Allure.
- Проверяются статус и тело по документации. Расхождения фиксируются.
