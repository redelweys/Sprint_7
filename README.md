# Sprint_7 — тестирование API Яндекс Самоката

Автотесты проверяют создание и вход курьера, создание заказа и получение списка заказов. Для создания заказа проверяются четыре варианта: BLACK, GREY, оба цвета и отсутствие поля color.

[Документация API](https://qa-scooter.education-services.ru/docs/)

## Запуск тестов и просмотр отчёта

Команды для PowerShell из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest test -v --alluredir=target/allure-results --clean-alluredir
allure serve target/allure-results
```

## Результат прогона

8 ноября 2026 года: 17 проверок, 13 прошли, 4 упали.

Сценарий: Создание курьера с занятым логином: с тем же или с другим паролем
Ожидание по документации: `409`, сообщение `Этот логин уже используется`
Фактический результат: В обоих случаях статус `409`, сообщение `Этот логин уже используется. Попробуйте другой.`


Сценарий: Создание курьера без `firstName`
Ожидание по документации: Отказ в создании - поле указано как обязательное; в тесте ожидается `400`
Фактический результат: `201 Created`, тело `{"ok": true}`


Сценарий: Вход курьера без `password`
Ожидание по документации: `400`, сообщение `Недостаточно данных для входа`
Фактический результат: В автотесте — `ReadTimeout` через 10 секунд. При ручной проверке в Postman — `504 Gateway Timeout` и HTML от nginx примерно через 2 минуты.
